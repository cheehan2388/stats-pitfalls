## 它在做什麼

布林通道（Bollinger Bands）在移動平均的上下各畫一條線，距離是最近 N 根收盤價標準差的 k 倍。最常見的設定是 N = 20、k = 2。

```formula
上軌 = SMAₙ + k × σₙ　　下軌 = SMAₙ − k × σₙ
```

通道的寬度會跟著波動變化：市場平靜時收窄，劇烈波動時張開。它其實就是把滾動視窗版的 z-score 畫在價格圖上，價格碰到上軌等於「z = +2」。

常聽到的兩種用法是：把通道當成「價格的正常範圍」，碰到上軌視為超買、碰到下軌視為超賣；或是把通道收窄（擠壓）當成即將出現大行情的前兆。

## 它默默假設了什麼

- **常態分布**：「2 個標準差涵蓋約 95%」是常態分布的性質。報酬率是厚尾的，極端值比常態分布預期的多。
- **每根價格互相獨立**：更根本的問題在這裡。「95%」的說法把視窗裡的 20 個收盤價當成 20 次獨立抽樣。但價格是一步一步累積出來的，今天的價格等於昨天的價格加上今天的變動，相鄰的價格高度相關。
- **價格會回到均值**：把碰到上軌解讀成「太高了、該回檔」，等於假設價格會被拉回均線。走趨勢的價格沒有這種拉力。
- **波動穩定**：用過去 20 根的標準差預估現在的正常範圍，假設波動不會突然改變。實際上波動會叢聚，大波動之後常常接著大波動。

## 哪裡會壞掉

!!! pitfall "價格在通道外的時間不是 5%，而是 12% 左右"
    下方實驗用 N = 20、k = 2，在 30 條模擬路徑上統計：收盤價落在通道外的比例是 12.4%，是「常態」說法理論值 4.6% 的將近三倍。

    原因不只是厚尾。把趨勢和波動叢聚都調成 0，這個比例仍然有 10.6%。關鍵在於價格是累積出來的：在一個 20 根的視窗裡，最新的那根價格位在視窗的尾端，往往是離視窗平均最遠的幾根之一，因為它累積了最多步的變動。通道是拿最容易出界的那個點去和自己所在視窗的平均比。

!!! pitfall "走趨勢時，碰到上軌是延續的訊號，不是反轉"
    實驗預設每根平均上漲 0.2%。在這個設定下，收盤突破上軌之後，5 根後價格更高的比例是 67%。把趨勢強度調到 0.5%，這個比例升到 88%；調到 0，則是 49%，也就是丟銅板。

    三種情況下都沒有出現「碰上軌就容易回檔」的現象。沒有趨勢時是一半一半，有趨勢時反而是繼續漲的機會比較大。價格可以連續很多根貼著上軌走（實驗中最長連續 11 根收在上軌之外），這段期間每一根看起來都像「超買」。

!!! pitfall "大波動之後通道才張開，總是慢一步"
    通道寬度來自過去 N 根的標準差，所以一次大波動發生時，通道還是窄的，價格會直接衝出去；之後通道變得很寬，並且維持 N 根之久，即使市場已經恢復平靜。

    通道告訴你的是「過去 20 根有多亂」，不是「接下來會多亂」。

## 親手試試看

先把「趨勢強度」拉到 0，確認「突破上軌後 5 根仍上漲」接近 50%；再慢慢往右拉，看它怎麼一路升高。接著把「波動叢聚程度」從 0 拉到 0.95，觀察圖上通道忽寬忽窄的樣子。最後試著調整 k，看「收盤在通道外的比例」和理論值之間的差距有沒有消失。

## 比較穩健的做法

| 做法 | 怎麼算 | 優點 | 代價 |
|---|---|---|---|
| 布林通道 | 均線 ± k × 滾動標準差 | 通用、每個看盤軟體都有 | 出界率不是 5%；無法區分趨勢與反轉 |
| 自己量出界率 | 在自己的資料上統計實際出界比例，再回頭調整 k | 門檻的意義符合你的資料 | 需要足夠長的歷史；市場狀態改變時要重算 |
| 對報酬率設門檻 | 把「今天的報酬率」除以過去 N 根報酬率的穩健尺度 | 報酬率之間接近獨立，門檻的機率意義比較可靠 | 看不到價格水準，圖上不直覺 |
| 加上趨勢過濾 | 只有在長期均線走平時，才把碰到通道邊緣視為可能反轉 | 避開「貼著上軌一路走」的情境 | 多一個條件，訊號變少 |

!!! robust "不要引用 95%，先量出你自己的資料實際出界幾次"
    通道本身是一個好用的視覺化工具，它如實顯示了最近的波動有多大。出問題的是「95%」和「碰到就反轉」這兩個附加在上面的解讀。

    在把通道當成訊號之前，先在自己的資料上算兩個數字：收盤在通道外的比例，以及突破之後 5 根的漲跌比例。如果第二個數字不是明顯低於 50%，那麼「超買」這個詞在你的資料上就沒有根據。

```python
import pandas as pd

def band_stats(close: pd.Series, n: int = 20, k: float = 2.0) -> dict:
    mid, sd = close.rolling(n).mean(), close.rolling(n).std()
    above, below = close > mid + k * sd, close < mid - k * sd
    later_higher = close.shift(-5) > close
    return {"outside_pct": round((above | below).mean() * 100, 1),
            "up_after_break_pct": round(later_higher[above].mean() * 100, 1)}
```

## 一句話帶走

布林通道如實畫出最近的波動，但它不保證 95%，也不代表碰到邊緣就會反轉；先量自己的資料再下結論。
