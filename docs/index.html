你用的指標，
悄悄假設了什麼？

z-score、移動平均、布林通道、相關係數，每一個都帶著對資料的假設。市場資料常常不符合這些假設，而指標不會提醒你。這本圖鑑一頁拆解一個方法：它假設了什麼、哪裡會壞掉、可以改用什麼。

先玩右邊這個：把最大那根跳動往上拉，看第二大的事件怎麼從偵測中消失。

離群值偵測

踩雷指數 3 / 3： 結論可能相反

z-score 離群偵測

Z-score Outlier Detection

你想抓的離群值會先把標準差撐大，然後躲在被撐大的標準差後面，讓自己看起來很正常。

  • 常態分布
  • 尺度估計沒被污染
  • 平穩性

平滑與趨勢

踩雷指數 2 / 3： 訊號經常失真

移動平均

Simple Moving Average

均線永遠落後價格大約半個視窗；想讓它反應快一點，盤整時的假訊號就會跟著變多。

  • 區間內水準不變
  • 雜訊互相抵消
  • 沒有極端值

波動與通道

踩雷指數 3 / 3： 結論可能相反

布林通道

Bollinger Bands

「價格有 95% 的時間在通道內」和「碰到上軌就會回檔」，這兩句常見的說法在趨勢行情中都不成立。

  • 常態分布
  • 每根價格互相獨立
  • 價格會回到均值
  • 波動穩定

關聯與迴歸

踩雷指數 3 / 3： 結論可能相反

皮爾森相關係數

Pearson Correlation

一個離群點就能憑空製造出 0.6 的相關；而一條完美的 U 形曲線，相關係數卻可能接近 0。

  • 線性關係
  • 沒有離群點
  • 兩個序列皆平穩
