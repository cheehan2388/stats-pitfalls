今天的數字，
記得昨天多少？

時間序列分析問的其實就是這件事。氣溫、體重、股價，都是一個接一個按時間排好的數字。這個 Wiki 用白話把每個觀念和模型講一遍，再說明它在量化交易裡拿來做什麼。

先拖右邊的「記憶力」：0 是完全不記得昨天，1 是完全記得。看同一批隨機數字會變成什麼樣子。

學習路線

照這個順序讀，每一頁需要的觀念前面都已經出現過。順序由各頁的先備關係自動排出。

  1. 時間序列是什麼 按照時間先後排好的一串數字。順序本身就是資訊，打亂就失去意義。 概念 入門
  2. 白噪音 完全沒有規律、每一個數字都和前面無關的序列。它是所有模型用來對照的基準。 概念 入門
  3. 隨機漫步 每一步都隨機，但位置是累加的。純粹靠運氣，也能走出看起來像趨勢的路線。 概念 入門 可以動手玩
  4. 平穩性 一條序列的「脾氣」不隨時間改變：平均、起伏幅度、和過去的關係都維持一樣。 概念 進階 可以動手玩
  5. 自相關 衡量一條序列和「幾天前的自己」有多像。它是判斷資料有沒有記憶的第一個工具。 工具 進階 可以動手玩
  6. AR 模型 用「昨天的數值」預測今天的模型。一個參數決定記憶多強、被推開後多快回來。 模型 進階 可以動手玩
