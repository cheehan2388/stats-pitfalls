Z-score Outlier Detection

它在做什麼

z-score 回答一個很直覺的問題：「這個數值離平均有多遠？」只是它不用原本的單位（元、百分比），而是用「幾個標準差」當單位。這樣不同商品、不同時期的數值就能放在同一把尺上比較。

z = (x − μ) / σ

其中 μ 是樣本平均，σ 是樣本標準差（standard deviation）。最常見的用法是設一個門檻：|z| > 3 就當成離群值（outlier）。拿來標記異常成交量、異常報酬率、爆倉金額暴增的時刻，都是這個套路。

「3」這個數字來自常態分布：如果資料真的是常態分布，只有約 0.27% 的點會落在 3 個標準差之外。250 個交易日裡，平均不到 1 天。

它默默假設了什麼

  • 常態分布：門檻 3 對應「0.27%」這件事，只在資料是鐘形曲線時成立。市場的報酬率是厚尾（fat tail）的，極端值出現的頻率遠高於常態分布的預期，所以同一個門檻會標記出比你以為更多的點。
  • 尺度估計沒被污染：公式裡的 μ 和 σ 是用「包含離群值在內」的全部資料算出來的。它假設這些離群值不會嚴重影響 μ 和 σ。但標準差是用距離的平方計算的，一個極端值的影響會被放大很多。
  • 平穩性：用同一組 μ 和 σ 去衡量每一個點，等於假設整段期間的平均和波動都沒變。市場的波動是一陣一陣的，平靜期的「異常」放到動盪期根本不算什麼。

哪裡會壞掉

遮蔽效應：離群值把 σ 撐大，然後躲在後面

下方實驗的 250 天模擬報酬率，原本的標準差大約是 1.4%。植入 5 個極端事件（最大 ±25%）之後，標準差被撐大到 2.77%，幾乎是兩倍。

結果是：5 個事件裡，那兩個 −5% 和 −4.5% 的事件，z 分數只剩 1.8 和 1.6 左右，遠低於門檻 3。傳統 z-score 只抓到 3 個，漏掉 2 個。這兩天的跌幅是平常波動的三到四倍，卻被判定為「正常」。

更麻煩的是，離群值越多、越大，這個問題越嚴重。最需要偵測的時候，偵測器最不靈。

厚尾資料上，「3 個標準差」不代表「千分之三」

把實驗的植入事件數調成 0，只留下厚尾的雜訊。250 個點裡傳統 z-score 仍然標記了 3 個點，是常態分布預期（不到 1 個）的好幾倍。

這些點不是「錯誤」，它們是厚尾資料的日常。如果你把每一個 |z| > 3 都當成值得交易的異常訊號，你會收到比預期多很多的訊號，而且大部分只是這種資料本來就會有的樣子。

用整段資料的 σ，等於偷看未來

回測時如果用「整段歷史」算 μ 和 σ，再回頭標記每一天，那麼 1 月的 z 分數其實用到了 12 月的資料。實際交易時你不可能知道未來的波動，回測出來的訊號會比實際能拿到的漂亮。

親手試試看

先看預設狀態下「傳統 z-score 抓到」和「穩健 z-score 抓到」這兩個數字的差別。接著把「最大事件的幅度」往右拉，注意「標準差 σ」怎麼跟著變大，而「穩健尺度」幾乎不動。最後把事件數調成 0，看看單純的厚尾會讓兩種方法各標記幾個點。

你會發現穩健 z-score 標記的點比較多（預設狀態下共 10 個，其中 5 個是植入事件）。這不是它比較「吵」，而是它的尺度沒有被撐大，所以厚尾資料本來就有的極端值也被如實標出來。門檻要設多少，應該依你的資料決定，而不是直接沿用 3。

比較穩健的做法

做法 怎麼算 優點 代價
傳統 z-score (x − 平均) / 標準差 簡單、人人看得懂 平均和標準差都會被離群值拉走
穩健 z-score (x − 中位數) / (1.4826 × MAD) 將近一半的資料是離群值時仍然穩定 資料有大量重複值時 MAD 可能為 0
分位數門檻 直接取第 0.5 與 99.5 百分位當界線 不需要任何分布假設 一定會標記固定比例的點，即使根本沒有異常
滾動視窗 只用過去 N 天的資料計算尺度 能跟上波動的變化、不偷看未來 視窗內剛發生過的極端事件會暫時撐大尺度

改用中位數與 MAD，並且只用過去的資料

MAD（median absolute deviation，中位數絕對偏差）是「每個點到中位數的距離」的中位數。乘上 1.4826 之後，在常態資料上它會等於標準差，所以門檻可以沿用同樣的直覺。

因為中位數只看排序、不看數值大小，一個 ±25% 和一個 ±250% 的事件對它的影響完全相同。實驗中植入事件後，穩健尺度只從 1.12% 變成 1.21%。

import pandas as pd

def robust_z(x: pd.Series, window: int = 250) -> pd.Series:
    past = x.shift(1).rolling(window)          # 只用過去的資料
    med = past.median()
    mad = past.apply(lambda w: (w - w.median()).abs().median(), raw=False)
    return (x - med) / (1.4826 * mad)

如果資料裡有很多 0（例如大部分時間沒有爆倉的爆倉金額），MAD 會變成 0，穩健 z-score 會除以零。這種零膨脹的資料應該先把「有沒有發生」和「發生時有多大」分開處理。

一句話帶走

標準差會被你想抓的離群值撐大；想偵測異常，尺度要用不會被異常影響的中位數與 MAD。

相關方法

  • 皮爾森相關係數：一個離群點就能憑空製造出 0.6 的相關；而一條完美的 U 形曲線，相關係數卻可能接近 0。
