它在做什麼

簡單移動平均（simple moving average，SMA）把最近 N 根 K 線的收盤價加起來除以 N。每多一根新的 K 線，就把最舊的那根丟掉、把最新的加進來。

SMAₜ = (Pₜ + Pₜ₋₁ + … + Pₜ₋ₙ₊₁) / N

它的用意是把上上下下的雜訊平均掉，留下比較平滑的「趨勢」。常見用法有兩種：看價格在均線之上還是之下來判斷多空，以及看短均線與長均線的交叉（黃金交叉、死亡交叉）當成進出場訊號。

它默默假設了什麼

  • 區間內水準不變：平均值要能代表「現在的水準」，前提是這 N 根 K 線的真實水準差不多。價格在走趨勢時，N 根之前的價格和現在已經不在同一個水準，平均出來的是「過去 N 根的中間點」，不是現在。
  • 雜訊互相抵消：平均能消除雜訊，是因為假設雜訊有正有負、彼此獨立。市場的波動會叢聚，連續幾根同方向的大波動並不會互相抵消。
  • 沒有極端值：平均對每一根 K 線給一樣的權重，一根異常的長影線或錯價會直接被算進去，而且會留在視窗裡 N 根之久。

哪裡會壞掉

落後大約 (N − 1) / 2 根，而且沒有辦法消除

N 根價格的平均，重心落在視窗的正中間，也就是 (N − 1) / 2 根之前。價格以固定速度上漲時，均線顯示的其實是那麼多根之前的水準。

下方實驗中 N = 20，理論落後 9.5 根，實際量到約 8.5 根。把 N 調到 60，落後變成約 28.6 根：趨勢已經走了一個多月，均線才剛反映出一半。等「價格站上均線」的訊號出現時，一段行情往往已經過了一大截。

盤整時頻繁穿越，每一次都長得像訊號

實驗最後 100 根是沒有趨勢的盤整，價格只是在固定水準附近隨機跳動。N = 20 時，價格在這段期間穿越均線 41 次。把 N 縮短到 5 想減少落後，穿越次數反而增加到 51 次。

這些穿越沒有任何預測意義，但在圖上它們和趨勢起點的那一次穿越長得一模一樣。縮短視窗換來的是更多雜訊，拉長視窗換來的是更多落後，兩者無法同時改善。

一根異常值會留下 N 根的殘影，然後突然消失

實驗的第 50 根有一次 +20 的異常跳動。它讓 20 期均線整整 20 根都被抬高約 1.0（也就是 20 / N）。到了第 70 根，這個異常值離開視窗，均線又突然掉回原位。

那一次「下跌」並不是市場發生了什麼，只是 20 根之前的舊資料被丟掉了。均線的每一次變動都同時受到「新進來的」和「剛離開的」兩根 K 線影響，而後者和現在的市場毫無關係。

親手試試看

慢慢把「視窗長度 N」從 5 拉到 80，同時盯著兩個數字：「趨勢段平均落後」會一路變大，「盤整段穿越均線次數」會一路變小。接著把「第 50 根的異常跳動」拉大，看橘色均線上那個平台狀的凸起，以及綠色的滾動中位數為什麼幾乎不動。

比較穩健的做法

做法 怎麼算 優點 代價
簡單移動平均 最近 N 根等權重平均 最容易理解與溝通 落後 (N − 1) / 2 根；異常值離開視窗時會突然跳動
指數移動平均 越近的資料權重越高，權重逐漸衰減 沒有「離開視窗」的突然跳動；對最新變動的第一反應較快 平均落後和相同跨度的 SMA 一樣；異常值的影響不會完全歸零
滾動中位數 取最近 N 根的中位數 單根異常值幾乎沒有影響 落後程度和 SMA 相近；線條呈階梯狀
先過濾再平均 先把超過 k 倍 MAD 的值截斷，再做移動平均 保留平均的平滑感，同時不被極端值拉走 多一個需要決定的參數

先決定你能接受多少落後，再選視窗；異常值多就改用中位數

落後是平滑的代價，任何平均法都躲不掉，只能選擇要付多少。與其問「哪個 N 最好」，不如反過來想：你能接受晚幾根才知道趨勢改變？把那個數字乘以 2 再加 1，就是 SMA 視窗的上限。

如果資料常有錯價、長影線或爆量的單根 K 線，用滾動中位數代替平均。實驗中同一個 +20 的異常值只讓中位數移動了 0.07。

import pandas as pd

price = pd.Series([100, 101, 99, 120, 100, 102, 101, 100, 99, 101])
sma = price.rolling(5).mean()               # 被 120 拉高，持續 5 根
med = price.rolling(5).median()             # 幾乎不受影響
ema = price.ewm(span=5, adjust=False).mean()  # 影響逐漸衰減，不會突然消失
print(pd.DataFrame({"price": price, "sma": sma, "median": med, "ema": ema}).round(2))

一句話帶走

均線顯示的是半個視窗之前的市場；落後與假訊號只能二選一，選視窗就是在選你要付哪一種代價。
