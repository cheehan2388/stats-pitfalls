它在做什麼

皮爾森相關係數（Pearson correlation coefficient）用一個介於 −1 和 +1 之間的數字 r，描述兩個變數「一起變動」的程度。+1 表示所有點落在一條往右上的直線上，−1 是往右下的直線，0 表示看不出直線關係。

r = Σ (xᵢ − x̄)(yᵢ − ȳ) / √[ Σ (xᵢ − x̄)² × Σ (yᵢ − ȳ)² ]

分子是「x 偏離平均的量」乘上「y 偏離平均的量」再加總：兩者同時偏高或同時偏低時貢獻正值。分母只是把結果縮放到 −1 到 +1 之間。

大家拿它來找「連動」的商品、檢查投資組合是否分散、挑選配對交易的標的，或是判斷某個指標和未來報酬有沒有關係。

它默默假設了什麼

  • 線性關係：r 衡量的是「點有多靠近一條直線」，不是「兩個變數有沒有關係」。關係如果是彎的，r 可能很小，即使其中一個變數幾乎完全決定了另一個。
  • 沒有離群點：公式裡每個點的貢獻是兩個偏差相乘。一個在 x 和 y 上都離平均很遠的點，貢獻會以平方的速度變大，足以蓋過其他所有點。
  • 兩個序列皆平穩：r 假設每一對觀察值都是從同一個穩定的關係中抽出來的。兩個各自有長期趨勢的序列（例如兩種商品的價格水準）會因為「都在往上」而呈現高相關，即使它們之間沒有任何關聯。

哪裡會壞掉

一個離群點，就能從無到有製造出相關

下方實驗預設產生 60 個完全無關的資料點，它們的 r 只有 0.12。接著在右上角加入 1 個距離 8 個標準差的離群點，r 立刻變成 0.63。

r² = 0.40，照字面解讀是「X 解釋了 Y 四成的變異」。但這四成全部來自那一個點。市場資料裡這種點並不罕見：閃崩的那一天、財報公布的那一天，兩個商品同時出現極端值，就足以撐起整段期間的「高相關」。

關係很強但不是直線，r 會說「沒有關係」

把實驗切換到「U 形曲線」並且不加離群點。此時 Y 幾乎完全由 X 決定，但 r 只有 0.15，和「完全無關」時的 0.12 幾乎沒有差別。

原因是 U 形的左半邊貢獻負值、右半邊貢獻正值，加總後互相抵消。波動率和報酬率之間、價格偏離程度和後續回歸之間，都常常是這種「兩端高、中間低」的關係。看到 r 接近 0 就判定兩者無關，會錯過這類關係。

拿價格水準算相關，量到的是「兩者都在漲」

兩個都有長期上漲趨勢的價格序列，直接計算相關係數通常會得到很高的數值。這個數字反映的是「兩者都隨時間變大」，時間才是共同的原因。這種情況稱為假性相關（spurious correlation）。

想知道兩個商品是否連動，應該用報酬率（每天的變動）來算，而不是價格水準。兩個序列的報酬率如果沒有關聯，即使價格走勢圖看起來很像，相關係數也會接近 0。

親手試試看

先在「完全無關」的設定下，把離群點的距離從 0 慢慢拉到 12，盯著「皮爾森 r」和「斯皮爾曼 ρ」這兩個數字的差距，以及橘色迴歸線如何被那一個點撬起來。接著切換到「U 形曲線」並把距離調回 0，看看兩個係數各是多少。

注意 U 形曲線時，斯皮爾曼 ρ 也只有 0.28。它只看排名，能處理離群點和「彎曲但一路往上」的關係，但對先降後升的關係同樣無能為力。沒有任何一個數字可以取代先畫散布圖。

比較穩健的做法

做法 怎麼算 優點 代價
皮爾森 r 用原始數值計算共變異 最通用，和線性迴歸直接對應 對離群點極度敏感；只看得到直線關係
斯皮爾曼 ρ 先把數值換成排名，再算皮爾森 離群點最多只是「排名第一」，影響有限；能抓到單調的曲線關係 看不到非單調（例如 U 形）的關係
肯德爾 τ 計算「方向一致的配對」所占的比例 小樣本時更穩定，解讀直觀 數值通常比 ρ 小，不能直接互相比較
先畫散布圖 把所有點畫出來用眼睛看 離群點、曲線、分群一眼就看得出來 變數很多時無法逐一檢查

同時算皮爾森與斯皮爾曼，兩者差很多時就去看散布圖

兩個係數接近，表示關係大致是線性的，而且沒有被少數點主導。兩者差距很大（例如實驗中的 0.63 對 0.08）就是警訊：有離群點在主導結果，或者關係不是直線。

計算之前先確認兩件事：用的是報酬率而不是價格水準；樣本期間裡有沒有特別極端的幾天，拿掉它們之後結論是否還成立。

import pandas as pd

def corr_check(a: pd.Series, b: pd.Series) -> dict:
    ra, rb = a.pct_change().dropna(), b.pct_change().dropna()   # 用報酬率，不用價格
    pearson, spearman = ra.corr(rb), ra.corr(rb, method="spearman")
    return {"pearson": round(pearson, 2), "spearman": round(spearman, 2),
            "suspicious": abs(pearson - spearman) > 0.2}

一句話帶走

相關係數只衡量「有多像一條直線」；一個離群點能製造它，一條曲線能藏住它，所以先畫圖再相信數字。
