Autoregressive Model

一句話

AR 模型認為今天的數值，等於昨天數值的一部分，加上一個今天才出現的隨機變動。

生活中的比喻

浴缸裡的水溫。你倒進一壺熱水，水溫立刻升高。接下來它不會馬上回到原本的溫度，也不會一直維持，而是每分鐘散掉一部分的熱，慢慢靠近室溫。

保溫效果好的浴缸散得慢，隔很久還是熱的。保溫差的，沒多久就涼了。

對應到資料上：室溫是序列的長期平均，那壺熱水是一次突發的衝擊，保溫效果就是 AR 模型裡的「記憶力」。

它到底在說什麼

AR 是自我迴歸（autoregressive）的縮寫，意思是拿自己的過去來預測自己。最簡單的版本只看前一期，寫成 AR(1)：

Xₜ = c + φ × Xₜ₋₁ + εₜ
  • Xₜ：今天的數值。Xₜ₋₁：昨天的數值。
  • φ（讀作 phi）：記憶力，今天保留昨天的幾成。
  • c：一個常數，決定長期平均的位置。長期平均等於 c ÷ (1 − φ)。
  • εₜ：今天的隨機變動，是 白噪音。

整個模型的性格由 φ 決定：

φ 的值 行為
0 完全不記得昨天，就是白噪音
0 到 1 之間 被推離平均後，逐漸被拉回來。越接近 1 回來得越慢
等於 1 永遠不會回來，變成 隨機漫步
負值 今天高、明天就偏低，上下交替

只有 φ 在 −1 和 1 之間時，序列才符合 平穩性。

一次衝擊的影響每天剩下前一天的 φ 倍。影響剩下一半所需的時間叫做半衰期，等於 ln(0.5) ÷ ln(φ)。看更多期的版本寫成 AR(p)，原理相同。在 自相關圖上，AR 模型的特徵是直條逐漸變矮。

親手試試看

序列在第 60 天被推了一把。橘色虛線是模型預期這次衝擊還剩多少。把「記憶力」從 0.8 慢慢拉到 1，看橘線從「很快降到 0」變成「永遠不降」。

記憶力 0.8 時，半衰期是 3.1 天，10 天後衝擊只剩 11%。調到 0.95，半衰期拉長到 13.5 天，10 天後還剩 60%。0.8 和 0.95 看起來差不多，半衰期卻差了四倍多。

量化交易怎麼用

AR 模型把 均值回歸這個想法變成可以計算的數字。

對一條平穩的價差估計出 φ，就能算出半衰期，也就是偏離之後大約多久會回來一半。半衰期決定了持有時間的長短：半衰期 3 天的價差和半衰期 60 天的價差，是完全不同的交易。

import numpy as np
rng = np.random.default_rng(0)
x = [0.0]
for _ in range(500):
    x.append(0.8 * x[-1] + rng.normal())      # 模擬一條 φ = 0.8 的序列
x = np.array(x)
phi = np.polyfit(x[:-1], x[1:], 1)[0]         # 用昨天預測今天，斜率就是 φ
print(round(phi, 2), round(np.log(0.5) / np.log(phi), 1))

它也是更複雜模型的基礎零件。加上 MA 模型和差分就是 ARIMA；把同樣的想法用在波動上，就是 GARCH 模型。

它能告訴你什麼、不能告訴你什麼

能：把「會不會回來、多快回來」變成 φ 和半衰期兩個可以比較的數字。

不能：告訴你回歸的力量會不會持續。φ 是用過去估計的。一條價差過去的半衰期是 5 天，不代表下次偏離也會在 5 天內回來。

常見誤解

估計出來 φ 是 0.9，小於 1，所以一定會回歸

資料不多時，φ 的估計很不準，而且會偏低。把實驗的記憶力設成 1（真正的隨機漫步），用 60 天資料量到的卻是 0.87。要判斷 φ 是不是真的小於 1，需要專門的 ADF 檢定。

φ 越大，代表越容易預測

φ 接近 1 時，今天確實很像昨天，但這只是因為水準變動得慢。真正能拿來交易的是「變動」，而 φ 越接近 1，變動越接近無法預測的白噪音。
